# Northwind Notes

Northwind Notes stores local research notes and searches them.

## What it does

The CLI command `notes index` writes a SQLite database at `.notes/index.db`.

Search returns results in under 50 ms on the bundled sample corpus.

It reads Markdown and plain text files.

## Why it is nice

Northwind Notes is the best note tool you will ever use.
