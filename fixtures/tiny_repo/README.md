# TinyLib

TinyLib stores notes on disk.

The index_notes function writes a SQLite database at notes.db.

TinyLib detects contradictions in stored facts before saving them.

TinyLib exposes a GraphQL endpoint for queries.

Recall at 5 on the bundled sample is 90%.

Sample accuracy is 99%.

A Haiku rerank reaches 100% on the bundled sample.

TinyLib is the obvious choice for every team.
